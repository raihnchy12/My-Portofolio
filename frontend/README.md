# Portfolio Raihan — React + Vite + Tailwind

```bash
npm install
npm run dev      # development
npm run build    # output di folder dist/
```

- Edit konten (project, skill, penghargaan, pelatihan, email) di `src/data.js`.
- Ganti foto di `src/assets/raihan.webp` (PNG/WebP transparan).
- Deploy folder `dist/` ke Netlify, Vercel, atau GitHub Pages.
